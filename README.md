TailorBuddy – Full Stack Tailoring Platform

A modern full-stack web application that allows users to browse, customize, and order tailored clothing online. Designed to simplify the tailoring process with a smooth user experience and real-time interaction.

 Features
Browse different clothing styles and categories
 Customize outfits based on user preferences
 User authentication (login/signup)
 Order placement and management system
 Dynamic and responsive UI
 Fully deployed and accessible online
 Tech Stack
